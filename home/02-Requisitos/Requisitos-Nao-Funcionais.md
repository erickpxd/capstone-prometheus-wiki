# Requisitos Não Funcionais

## Objetivo

Os requisitos não funcionais representam os atributos de qualidade priorizados durante o desenvolvimento do Prometheus V2.

| Código | Requisito |
|---------|-----------|
| RNF01 | O sistema deve possuir arquitetura modular. |
| RNF02 | O sistema deve facilitar manutenção e evolução. |
| RNF03 | O sistema deve permitir crescimento sem necessidade de reestruturação completa. |
| RNF04 | Os módulos devem possuir baixo acoplamento e alta coesão. |
| RNF05 | A comunicação entre módulos deve ocorrer por APIs bem definidas. |

## Atributos de Qualidade Priorizados

- Modularidade
- Escalabilidade
- Manutenibilidade
- Disponibilidade
- Reutilização
