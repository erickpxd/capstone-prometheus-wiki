# Cronograma

O desenvolvimento do Prometheus V2 foi dividido em etapas, acompanhando as atividades previstas no Capstone.

| Etapa | Descrição |
|--------|-----------|
| Levantamento | Identificação das limitações do Prometheus V1 |
| Arquitetura | Definição da arquitetura proposta |
| Modelagem | Elaboração dos diagramas C4 |
| Documentação | Produção da documentação técnica |
| Avaliação | Análise de trade-offs |
| Entrega | Apresentação final do projeto |
