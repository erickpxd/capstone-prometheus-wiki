# Requisitos Funcionais

## Objetivo

Os requisitos funcionais descrevem os principais serviços que o Prometheus V2 deverá oferecer, preservando as funcionalidades já existentes no Prometheus V1 e permitindo sua evolução arquitetural.

| Código | Requisito |
|---------|-----------|
| RF01 | Permitir autenticação de usuários. |
| RF02 | Permitir gerenciamento de usuários. |
| RF03 | Permitir gerenciamento de cursos. |
| RF04 | Permitir gerenciamento de conteúdos das disciplinas. |
| RF05 | Permitir registro e consulta de notas dos alunos. |
| RF06 | Permitir acesso aos vídeos e materiais didáticos. |
| RF07 | Disponibilizar APIs para comunicação entre os módulos do sistema. |

## Observações

Esses requisitos representam os principais domínios identificados durante o reprojeto arquitetural e servirão como base para organização dos módulos da aplicação.
